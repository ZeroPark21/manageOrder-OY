🧪 Chrome Extension 테스트 페이지

✅ 테스트 페이지가 준비되었습니다

테스트 방법

  1. Chrome Extension 새로고침:
    chrome://extensions/ 페이지에서 TikTok Ads Auto Downloader 확장 프로그램을 찾아 새로고침 버튼을 클릭하세요.
  2. 개발자 콘솔 열기:
    F12 키를 눌러 개발자 도구를 열고 Console 탭을 선택하세요.
  3. Content Script 확인:
    콘솔에 "TikTok Ads Auto Downloader content script loaded" 메시지가 표시되는지 확인하세요.
  4. Extension Popup 열기:
    브라우저 툴바에서 확장 프로그램 아이콘을 클릭하여 팝업을 엽니다.
  5. 통신 테스트:
    아래 "통신 테스트" 버튼을 클릭하여 Background Script와의 통신을 테스트하세요.
