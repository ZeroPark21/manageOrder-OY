# 코딩 표준 - 하드코딩 금지 원칙

## 절대 금지 사항

### 하드코딩 금지 대상
1. **숫자 데이터**: 통계, 카운트, 합계, 평균 등 모든 계산된 값
2. **동적 텍스트**: 상태 메시지, 사용자명, 제품명 등 변동 가능한 텍스트  
3. **설정 값**: API 엔드포인트, 임계값, 제한값 등 비즈니스 로직 관련 수치

## 필수 준수 원칙
- **API 우선 원칙**: 모든 동적 데이터는 API에서 가져오기
- **단일 데이터 소스**: 관련 데이터는 동일한 API 사용
- **타입 안정성**: TypeScript 인터페이스로 데이터 구조 명확화
